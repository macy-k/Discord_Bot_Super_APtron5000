<h1>Super APtron5000</h1>

Simple discord bot I made for a friend. Specifically, it was for a Project Sekai tiering event.

Allows each user to keep a count that they can
- increment
- decrement
- reset 
- view


Also includes a save function, allowing users to have multiple saved counts
they can switch between. 

---

Note the language includes "AP" which is specific to Project Sekai, but can be changed out easily if needed :)


**BEWARE** this keeps an SQLite database that is never really cleaned out. The more users/saves
this has the large the DB will get, so be sure you're ok with that if running this on your own machine.
